Unified Catalog explorer — one surface, many lenses

The Catalog Explorer is the Phase 1 primitive that picks #3 (New Arrivals), #4 (Rotation browser), and #9 (Browse-by-label/genre/era) all plug into. Rather than ship three separate views with three flavors of list / filter / sort behavior, we ship one list surface and compose a lens with filter and sort options.

Each lens is just a pre-baked query against /library/query plus a per-lens secondary filter row (window for New Arrivals, tier chips for Rotation, label selector for By Label, genre selector for By Genre). The list/grid toggle, the row layout, and the drill-in to Album Detail are shared across every lens — so adding a new lens later (era, country, decade, your own bin) is a small addition, not a new feature.

This makes #3 / #4 / #9 fall out of one cohesive design instead of three competing ones.

Try it

  • Switch between the 5 lenses in the top chip row
  • In New Arrivals, switch the 30D / 90D / All-time window
  • In Rotation, multi-select H / M / L / S tier chips
  • In By Label and By Genre, pick a facet
  • Toggle list ⇄ grid in the top-right of the filter row
  • Tap any album → Album Detail with streaming URL buttons (Pick #2)
  • On Album Detail, tap a track row to simulate preview playback

BS contract — one endpoint per the substrate

GET /library/query ?lens=all|new|rotation|label|genre &sort=add_date_desc|title_asc|year_desc &tier=H,M,L,S // rotation lens &label=merge // label lens &genre=indie-rock // genre lens &era=2020s // future lens &window=30d|90d|all // new arrivals lens &cursor=<page>

Rotation membership comes from joining rotation onto library on the backend; the Rotation lens is the only one that needs it. LML proxy/metadata/album on detail surfaces the Spotify / Apple Music / Bandcamp URLs for Pick #2 streaming preview.

Substrate, not a feature. Album Detail in this prototype is the same view that backs per-album histogram (Pick #15), Album condition (Pick #5), and Memos (Pick #6). Every later catalog-touching feature plugs into this same row → detail pipeline — so the cost of Phase 2 picks comes down.
