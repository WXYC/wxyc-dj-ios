Phase 0 — QR sign-in

Phase 3 — Personal stats + profiles

Per-DJ plays endpoint lights up · ADRs 0006 / 0008 gating

Five picks consume the play-data substrate (ADR 0006 per-DJ + ADR 0008 per-album): Underplayed Gems, Diversity Readout, Bin Maturity, DJ Profile, per-album histogram. Shipping the play-data picks together amortizes the API integration cost.
