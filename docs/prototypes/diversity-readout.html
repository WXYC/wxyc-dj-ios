Diversity Readout, with Top Played folded in

This is iOS pick #10 with the histogram requirement layered on. Six coequal axes (artist · album · label · genre · era · new-vs-catalog). Locale stays the v2 7th. The four-window picker (30D / 90D / 1Y / All) drives every card. Each card shows the top 3 with counts and is tappable — the drill-in is the "Top Played" view for that axis.

Try it

  • Tap a window in the segmented picker — values change across all cards
  • Tap any axis card to drill into the sorted list
  • Drill-in rows show name + count + proportional bar (Q15b → A)
  • Tap Back or Diversity to return
  • The drill-in inherits the Readout's window (Q15c → A) — visible in the subtitle

What's the same in the BS contract

GET /djs/{id}/play-stats?window=30d|90d|1y|all from ADR 0006 — extended with one new field: albums: [{id, title, artist_name, count}] for the new Albums axis. No new endpoint.
