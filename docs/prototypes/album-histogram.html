Per-album play histogram — Swift Charts, snap-aligned scroll

Each Album Detail view gets a station-wide history of how often this exact release has spun on WXYC. The chart surface mirrors Apple Health: y-axis pinned at left, x-axis ticks below, snap-aligned horizontal momentum scroll, single tap raises a floating tooltip. Swift Charts in iOS 18 hits this shape natively — BarMark + chartScrollableAxes(.horizontal) + chartScrollTargetBehavior(.valueAligned).

Per-DJ stories don't live here. "Who plays this most" is answered by the Bin Maturity badges and the Diversity Readout's Top Played rollups; mixing those into the Album Detail would invite per-DJ jealousy reads that the station has explicitly avoided. The page answers "how often does this album get played?", not "who plays it?".

Default granularity is span-based: if the album's play span (first → last) exceeds 5 years, default to Year; otherwise Month. The user can flip either way with the segmented control — both granularities ship in one payload so the toggle is instant and never re-fetches.

The dashed orange RuleMark labelled "Released YYYY" only renders when the release year sits before the first-play year. For everything new (release year == first-play year, the common case), the marker would add chrome and no insight — Polvo's 1993 release first hitting WXYC in 2017 is the kind of long-tail catalog story the marker is here to tell.

Try it

  • Switch albums in the top toggle — watch the chart shape, marker, default granularity, and summary line all swap
  • Toggle Year / Month — the same payload renders both granularities, no re-fetch
  • Scroll the chart horizontally — bars snap one notch per swipe (Apple Health momentum)
  • Tap any bar — tooltip floats above with period + count, bar brightens + lifts
  • The Squid · Bright Green Field variant shows the empty-state caption — no segmented control, no chart

BS contract

GET /library/{album_id}/play-stats
Returns: {
  year_counts:  { "2017": 1, "2018": 12, ... },
  month_counts: { "2017-08": 1, "2018-03": 2, ... },
  first_played_at, last_played_at, total_plays
}

60s TTL cache on the API side. Both granularities in one payload — Year/Month toggle never triggers a second round trip. Release year comes from LML's /proxy/metadata/album as best-effort; if LML 404s or rate-limits, the marker is silently omitted (the histogram itself still renders fine).

Deferred to v2

  • Per-DJ filter (out of scope; lives in Bin / Diversity instead)
